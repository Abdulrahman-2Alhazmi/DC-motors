# 🚗 Arduino 4 DC Motors Control using L293D

This project demonstrates how to control **4 DC motors** using an **Arduino Uno** and **two L293D Motor Driver ICs**. The robot performs a sequence of movements automatically based on predefined timing.

---

## 📌 Project Description

The Arduino controls four DC motors through two L293D motor drivers. The robot follows a predefined movement sequence:

- ▶️ Move Forward for **30 seconds**
- ◀️ Move Backward for **1 minute**
- ↔️ Turn Right and Left alternately for **1 minute**

This project demonstrates the basics of motor control and robot movement programming using Arduino.

---

## 🛠️ Components Used

- Arduino Uno
- 2 × L293D Motor Driver IC
- 4 × DC Motors
- Breadboard
- Jumper Wires
- USB Cable / External Power Supply

## 📖 How It Works

1. Initializes all motor control pins.
2. Sets the motor speed to maximum using PWM.
3. Moves the robot forward for **30 seconds**.
4. Moves the robot backward for **1 minute**.
5. Alternates between right and left turns every **5 seconds**.
6. Repeats the sequence continuously.
